# 🧠 AI Code Explainer

### A clean, modern web app that helps beginners understand code snippets using advanced AI. Simply paste your code, provide a Groq API key, and get step-by-step, simple explanations powered by LLaMA 3.

## ⚙️ Features

<table>
  <tr>

## 🔐 Privacy First

> **Your API key and code never leave your browser (except when sent directly to the Groq API).**
> We do not use any databases or backend servers. The entire app runs strictly on the client side. Your API key is held locally in the DOM session and sent straight to the official Groq API endpoint. No tracking, no data storage.
